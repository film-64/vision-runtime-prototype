# Historical execution evidence

These pages are sanitized summaries of dated validation archives from the source `yoloe26-smoke` branch. They preserve the engineering claim and measurement boundary without redistributing the original media, model weights, generated checkpoints, raw machine paths, or private runtime environment.

Included summaries:

- [YOLO26 Pose sparse / ONNX](yolo26-pose-sparse-onnx.md)
- [OCR region-shape performance](ocr-region-performance.md)
- [YOLOE26 fused/local execution](yoloe26-fused-local.md)

## Interpretation rule

Each result is a historical snapshot tied to its recorded model, input, hardware/runtime and timing boundary. The numbers are not current product guarantees and should not be generalized beyond the stated experiment.

The public repository intentionally does not promise full reproduction of these runs. The source archives recorded their own input hashes, raw results and tools; this showcase carries only the parts needed to demonstrate that the runtime was actually exercised, measured and validated during development.
