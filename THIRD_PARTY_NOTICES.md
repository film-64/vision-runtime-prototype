# Third-party scope notes

This showcase does not redistribute model weights, generated checkpoints, private media, face data, or third-party model/runtime source trees.

The historical evidence summaries refer to components used in the original development environment, including Ultralytics YOLO/YOLOE, ONNX Runtime, PyTorch, and PaddleOCR / PP-OCRv5. Those components and any model artifacts remain governed by their respective upstream licenses and terms.

The code extracted into `vision_runtime/` is the runtime-control layer from the source repository and is distributed here under the repository license. No third-party model artifact is required to run the included synthetic tests or control-core example.
