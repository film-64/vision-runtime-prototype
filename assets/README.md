# Showcase assets

This directory is reserved for sanitized presentation material such as:

- a historical runtime UI capture showing that the system executed;
- a development requirement sketch showing how runtime behavior was specified;
- a sanitized capture of the original private development repository, if useful for provenance.

Do not add copyrighted test-video frames, face/identity material, machine-local paths, tokens, private issue/branch details, or unpublished internal experimental material.

No visual asset is included in the initial migration because the source repository's historical sample media is not treated as public showcase material.
